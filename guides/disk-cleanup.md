# Disk Cleanup

Free up space on the C: drive by removing temporary and unneeded files.

**When you'd use it:** the C: drive is getting full, or a PC is slow and low on space.

## Steps
1. Search for **Disk Cleanup** from the taskbar and open it. It opens on the **C:** drive.
2. It lists file types it can remove, such as Downloaded Program Files, Temporary files, DirectX Shader Cache and the Recycle Bin.
3. I ticked **Recycle Bin**, **Temporary files** and **Downloaded Program Files**.
4. Clicked **Clean up system files**. It scans and calculates how much space can be freed: **1.24 GB** on my PC.
5. Back on the Disk Cleanup for C: page, clicked **OK**, then confirmed that I wanted to permanently delete the files.

## Check it worked
Reopening Disk Cleanup showed the Recycle Bin and the other selected items at **0 bytes**, so the files were removed.

## What I learned
- **Clean up system files** finds extra space, such as old Windows Update files, that the first scan doesn't include.
- Deleted files are gone permanently, so check what's ticked, especially the Recycle Bin, before confirming.
