# Windows Update

Keep Windows patched for security, stability and performance.

**When you'd use it:** a user's PC is missing updates, is behind on security patches, or an app needs a newer Windows build.

## Steps
1. Open **Settings › Windows Update**.
2. Click **Check for updates**. Windows contacts Microsoft's servers, then downloads and installs anything new.
3. If the PC is already current it shows that it's up to date. Mine was, because I'd updated the day before.

## The other options on the page
- **Pause updates:** delays updates for a set time, e.g. so a restart doesn't interrupt work.
- **Update history:** lists what has been installed. Mine shows a lot of **security updates**, a sign of how often Microsoft patches against new threats.
- **Advanced options:** further settings for how and when updates install.

## What I learned
- Updating regularly matters for **security**, and also for **functionality and performance**.
- Update history is a quick way to see whether a PC is being patched.
